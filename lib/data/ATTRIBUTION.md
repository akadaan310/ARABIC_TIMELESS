# Data sources and licensing

The JSON bundles in this directory are **derived data**, generated by
`scripts/build-lexicon.mjs` from two open sources. Neither is authored here.

## Sources

### 1. Quranic Arabic Corpus — morphology

- Upstream: <http://corpus.quran.com> (morphology v0.4)
- Obtained via: [`mustafa0x/quran-morphology`](https://github.com/mustafa0x/quran-morphology),
  a fork with root and lemma corrections
- Provides: root, lemma, part of speech, verb form and grammatical features for
  all 130,030 morphological segments across 77,429 tokens
- **Licence: GNU GPL**

Citation:

> Dukes, K. (2011). *The Quranic Arabic Corpus.* <http://corpus.quran.com>

### 2. quranwbw — word-by-word glosses

- Obtained via: [`qazasaz/quranwbw`](https://github.com/qazasaz/quranwbw)
- Provides: English gloss and transliteration for each of 77,431 words, plus
  6,236 ayah-level translations
- Descends from the Quranic Arabic Corpus word-by-word data
- **Licence: GNU GPL**

## What is derived here

The two sources are joined on token position (`surah:ayah:word`). That join
produces something neither carries on its own: for each root, the set of English
glosses belonging to every word built on it — the root's semantic field, read
off the data rather than hand-authored.

| File | Contents |
|---|---|
| `roots.json` | 1,651 roots → display form, frequency, glosses, lemmas |
| `lemmas.json` | 4,241 lemmas → root, frequency, glosses, part of speech |
| `surface.json` | 16,722 written forms → root, lemma, POS, verb form, gloss |

Surface forms are indexed under two normalisations, because Quranic orthography
writes a superscript alef where modern Arabic writes a full ا. Without both, a
pasted modern passage cannot find a Quranic entry.

## Consequences

Because both upstream sources are GPL, **this derived data is GPL**. Anything
distributing it inherits that obligation. The engine code in `lib/engine/` does
not depend on the data to run — it degrades to pattern-based root extraction —
so removing this directory is a supported configuration, not a broken one.

## Coverage

The lexicon is Quranic. It covers classical vocabulary thoroughly and modern
Arabic partially: a pasted modern passage will resolve its classical core and
leave newer words unresolved. The engine reports that as unresolved rather than
guessing, because a lexicon reporting its own coverage is not reporting the text.
